# v1.0.0
- Initial release, a Geode v6 port of the Daily Demon mod reworked into Hourly Level
- Map Pack button in the Creator menu replaced by an Hourly Level button
- Event-style Hourly Level popup that resets every hour (UTC)
- Lock button on level pages: PIN prompt, then a menu to set the Hourly Level (PIN + account whitelist checked by the server, no Argon)
- Configurable server URL
